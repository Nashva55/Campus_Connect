Foundation

What this domain is about

Cybersecurity is more than tools. It begins with understanding how systems, networks, authentication, and applications behave, then learning how to secure or test them responsibly.

Roadmap

Step-by-step learning path

Move through these stages in order and build at least one project in each phase.

Step 1

Learn how systems really work

Security skill grows from fundamentals, not from jumping directly to advanced tools.

  • Study networking models and protocols
  • Understand Linux and Windows basics
  • Learn authentication and access control concepts
Step 2

Practice safe labs

Use intentionally vulnerable systems and legal practice environments.

  • Try CTF platforms and labs
  • Use Wireshark, Nmap, and Burp Suite carefully
  • Write down what you find and why it matters
Step 3

Focus on web and app security

Many student projects and entry roles touch application security directly.

  • Learn OWASP Top 10 concepts
  • Understand validation and session issues
  • Review secure coding basics
Step 4

Build a security portfolio

Your reports, lab notes, and structured analysis matter as much as the tools you use.

  • Publish learning writeups
  • Document findings clearly
  • Practice explaining risk and remediation
